# roast-the-gadget — a one-line roast of the alarm clock

An entry for make.fun's [One-Line Roast: The Gadget You Use Every Day](https://make.fun/bounty/u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610) bounty.

`main.py` writes one line to `/output/entry.txt`:

> My alarm clock has exactly one job, and it outsources it to the snooze button nine times every single morning.

The line is 110 code points, inside the gate's 1 to 200 character limit.
The program creates `/output` if needed and checks the line against the
limit before writing it, with no trailing newline.
